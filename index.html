Task Bot — チームタスク管理・自動通知システム

困っていたこと
リモートチームのタスク共有が「毎朝の手動投稿とスレッド返信」頼み。投稿する人の負担が大きく、期日超過の見逃しも起きていました。
作ったもの
Notion・Slack・Googleカレンダーをつないだ自動通知Bot。毎朝、各メンバーに予定と未完了タスクをDMし、リーダーには期日超過の一覧を届けます。週次レポートはグラフ付きで自動生成。
どう変わったか
毎朝の投稿作業がゼロに。GitHub Actionsの定時実行なのでランニングコストも0円。導入から現在まで毎日稼働しています。

Python / Notion API / Slack API / Google Calendar API / GitHub Actions

困っていたこと
出品のたびに商品名と説明文を考えるのに1品10分。写真は撮ってあるのに、文章づくりで手が止まっていました。
作ったもの

模擬案件 — 架空のご依頼を想定した自主制作

問い合わせ集約 + AI自動分類 — クレームを見逃さない仕組み

想定した困りごと
不動産会社で、問い合わせがメールとLINEに分かれて届く。担当者が両方を見張っていないと取りこぼし、特にクレームの初動が半日遅れると大きな問題になる。
作ったもの
LINEに届いた問い合わせをAI(Claude)が「賃貸・売買・内見・クレーム・その他」に自動分類し、Slackの担当チャネルへ振り分け。クレームと判定したものだけ、営業部長の個人LINEへ即通知します。
ポイント
クレーム受信から通知まで実測約14秒(目標は5分以内)。同じ通知が二度飛ばない設計や、なりすまし防止の署名検証まで作り込み、本番環境で実際に動くところまで確認しています。

CSチャットボット — AIが一次対応し、難しいものは人へ

想定した困りごと
ECサイトに月500件ほど届く問い合わせを、オペレーター2名では捌ききれず、返信に1〜2日かかっていた。
作ったもの
FAQをもとにAI(Claude)が自動で回答し、判断が必要な質問や強いクレームはAIが自分で判断して人間のオペレーターに引き継ぐチャットボット。夜間・休日はAIが一次対応し、「翌営業日に対応します」と案内して対応待ちリストに積みます。
ポイント
AIが「それっぽいけど間違ったこと」を答えてしまう不安に対して、回答の根拠(どのFAQか)を必ず示させ、根拠が無い場合はプログラム側で強制的に人へ引き継ぐ三重の対策を入れています。

社内文書検索AI — 「マニュアルどこ?」をなくす

想定した困りごと
社内マニュアルや規程がPDFで散在していて、必要な1行を探すのに時間がかかる。新人さんが同じ質問を何度もすることになる。
作ったもの
PDFを取り込んでおくと、普通の言葉で質問するだけで出典(どのファイルの何ページか)付きで答えてくれる検索AI。要件定義書の作成から、実装・テストまで受注を想定して一式作りました。
ポイント
「AIの答えが本当か確認できない」という不安に対して、必ず根拠の箇所を一緒に表示する設計にしています。

06FAQよくある質問

プログラミングのことが全然分からなくても依頼できますか?
はい、むしろそういう方のために作っています。「毎週この作業に2時間かかっている」のような、今の困りごとだけ教えてください。
何を用意すればいいですか?
特に何も要りません。今使っているファイル(ExcelやスプレッドシートのサンプルでOK)があれば話が早いですが、なくてもヒアリングで伺います。
途中で「やっぱりこうしたい」と変更できますか?
できます。小さな変更は制作中に2回まで無料で対応します。大きな方向転換の場合は、追加のお見積りを先にお出しして、ご納得いただいてから進めます。
AIの利用料など、納品後にお金はかかりますか?
ツールによります。AIを使うツールは月数百円〜の利用料がかかることが多いですが、Task Botのようにランニングコスト0円で組める構成もあります。お見積り時に必ず明示します。
会社の情報を渡しても大丈夫ですか?
いただいた資料は制作の目的以外に使いません。秘密保持契約(NDA)にも対応します。医療業界出身なので、扱いに気をつかう情報がある現場の感覚は理解しているつもりです。
